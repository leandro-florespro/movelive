# Agentes REIS [IA] — Resumo e Utilidade para a Movelive

---

## TIER 1 — Uso imediato e frequente

Esses agentes trabalham diretamente no seu dia a dia de produção.

### `direct-response-copywriter`
Escreve copy de vendas, landing pages, scripts de VSL, sequências de email, hooks, headlines e posts. Focado em conversão. **Para você:** escreve todo o texto das LPs dos seus clientes antes de você montar no AI Studio.

### `social-media-team`
Roteiros de Reels, carrosséis, calendário de conteúdo, análise de vídeos, scripts para gravação. Ativa para qualquer tarefa de conteúdo para Instagram, YouTube, LinkedIn. **Para você:** gera carrosséis completos para seus clientes e para o seu próprio perfil.

### `humanizer`
Pega copy gerado por IA e transforma em texto com voz humana brasileira — elimina padrões robóticos, injeta ritmo natural. Roda ANTES do reviewer. **Para você:** passa todo copy das LPs por aqui antes de entregar ao cliente.

### `reviewer`
Último controle de qualidade antes de publicar. Verifica voz de marca, frameworks de persuasão e humanização. Roda SEMPRE por último. **Para você:** validação final de qualquer entrega de copy ou conteúdo.

### `dev-agent`
Transforma especificações de design e copy em código HTML/React/Astro com Tailwind CSS. **Para você:** gera o HTML das LPs — use em conjunto com o direct-response-copywriter para um fluxo completo.

## TIER 2 — Uso estratégico e periódico

Esses agentes você usa para pensar e planejar, não para produção diária.

### `orchestrator`
Coordena múltiplos agentes para objetivos complexos e multi-etapas. É o "chefe" que distribui tarefas. **Para você:** use quando tiver um projeto grande, como "criar a identidade completa + LP + carrosséis para um novo cliente".

### `cmo-strategist`
Estratégia de marketing completa — ICP, funil, campanhas, coordenação de copy. **Para você:** use para montar a estratégia de cada cliente antes de produzir qualquer material.

### `market-research-analyst`
Análise de concorrentes, mapeamento de ICP, dores/desejos/objeções, oportunidades de posicionamento. **Para você:** pesquisa o mercado de personal trainers e corretores para embasar suas LPs.

### `personal-brand-strategist`
Constrói a persona pública de uma pessoa — arquétipo, narrativa, identidade visual, pilares de conteúdo. **Para você:** use para definir o posicionamento dos seus clientes PT e corretores, e também para o seu próprio @leandro.florespro.

### `chief-strategy-advisor`
Conselheiro estratégico de alto nível — visão de negócio, decisões críticas, frameworks estratégicos. **Para você:** use quando precisar tomar decisões importantes sobre a Movelive — precificação, expansão de nicho, posicionamento.

### `designer-agent`
Produz especificações visuais detalhadas — identidade de marca, layouts, componentes. Não executa código, só especifica. **Para você:** define a direção visual das LPs antes do dev-agent construir.

### `brand-site-builder`
Constrói sites completos de marca. **Para você:** útil quando um cliente quiser um site institucional além da LP.

## TIER 3 — Uso pontual e específico

Esses agentes têm funções muito específicas — você vai usar quando a situação pedir.

### `analysis-agent`
Lê e analisa arquivos do projeto, produz resumos estruturados para outros agentes. Não implementa nada. **Para você:** útil para analisar o perfil de um cliente e preparar briefing antes de criar a LP.

### `logo-brand-mark-designer`
Cria logos, ícones, favicons e marcas visuais em SVG. **Para você:** serviço adicional para clientes que precisam de identidade visual além da LP.

### `design-system-extractor`
Extrai design tokens, paletas, tipografia e padrões visuais de sites de referência a partir de uma URL. **Para você:** analisa o site de concorrentes ou referências para embasar o design das LPs.

### `creative-director`
Direção criativa visual — motion design, identidade, conceito. Usa Figma, After Effects, GSAP. **Para você:** use quando quiser elevar o nível criativo de uma entrega específica.

### `vfx-motion-designer`
Implementa animações, efeitos visuais e micro-interações em CSS/JS/Canvas. **Para você:** adiciona animações nas LPs quando quiser entregar algo premium.

### `company-brand-strategist`
Posicionamento e identidade de marca para empresas. **Para você:** use quando atender clientes que querem mais do que uma LP — uma marca completa.

### `product-brand-strategist`
Naming e branding de produtos específicos dentro de um ecossistema de marca. **Para você:** útil se um cliente quiser nomear e posicionar um programa ou serviço específico.

### `sdr-reis-ia`
Agente de SDR — qualifica leads, faz outreach, trata objeções e agenda reuniões. Focado no ecossistema REIS [IA]. **Para você:** serve como referência para quando você quiser montar seu próprio script de prospecção ativa.

### `executor-agent`
Configura plataformas externas — CRM, email marketing, ferramentas de booking. **Para você:** útil quando precisar configurar ferramentas para seus clientes (ex: Google Meu Negócio, ManyChat).

### `execution`
Executa implementações técnicas — cria arquivos, modifica código, organiza pastas. **Para você:** tarefas técnicas de organização de projetos.

## TIER 4 — Fora do seu escopo atual

Esses agentes são voltados para o ecossistema educacional do REIS [IA] — cursos, aulas, mentorias. Não se aplicam ao seu negócio agora.

### `education-director`
Estratégia curricular, design de cursos, pipeline educacional. Específico para criadores de cursos.

### `educational-designer`
Cria visuais para aulas — slides, mapas mentais, diagramas. Específico para gravação de aulas.

### `roteirista-aulas`
Escreve roteiros de aulas em vídeo. Específico para criadores de conteúdo educacional.

### `movement-brand-strategist`
Constrói movimentos e comunidades em torno de uma causa. Específico para líderes de comunidade.

## Fluxo recomendado para criar uma LP completa

```
market-research-analyst     → pesquisa o nicho e o cliente
        ↓
cmo-strategist              → define estratégia e posicionamento
        ↓
personal-brand-strategist   → define identidade do cliente
        ↓
direct-response-copywriter  → escreve todo o copy
        ↓
humanizer                   → humaniza o texto
        ↓
reviewer                    → validação final do copy
        ↓
designer-agent              → especificação visual
        ↓
dev-agent                   → gera o HTML
```
